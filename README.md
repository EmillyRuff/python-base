# 🚀 Python Base - Meus Estudos em Python

Este repositório contém os códigos e projetos que desenvolvi enquanto estudo Python. Aqui coloco em prática os conceitos aprendidos no curso, criando pequenos programas e experimentando novas funcionalidades.

## 📌 Projetos incluídos

- **Tabuada** (`tabuada.py`) - Gera e exibe a tabuada do 1 ao 10 de forma formatada.
- **Hello World** (`hello_world.py`) - Exibe "Hello, World!" em vários idiomas.
- **Interpolação** (`interpolacao.py`) - Demonstra diferentes formas de interpolação de strings em Python.

## O que estou aprendendo?
Sintaxe básica do Python
Estruturas de repetição e condicionais
Manipulação de strings e listas
Interpolação de strings (f-strings, .format(), %)
Funções e modularização
Manipulação de arquivos e entrada/saída
E muito mais!

Este repositório é apenas para aprendizado pessoal, mas fique à vontade para explorá-lo e sugerir melhorias. 😃
